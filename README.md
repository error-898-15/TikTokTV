## About

TikTok TV is an Android TV app that brings the TikTok-style scrolling video experience to the big screen. No touch screen needed, everything works with the TV remote (D-pad).

## Features

- Auto-scrolling video feed, just sit back and watch
- Remote control friendly navigation
- Genre categories to find the videos you like
- Profile screen with a grid of the creator's videos
- Like, comments and more options on every video
- TikTok logo splash when the app opens

## Remote Controls

| Button | Action |
| ------ | ------ |
| Left / Right | Previous / next video |
| Down | Show the action bar (like, comments, more, profile) |
| Up | Show genre categories |
| OK / Select | Choose the highlighted item |
| Back | Go back / close the open panel |

## Install on Android TV

1. Download the APK from the [Releases page](https://github.com/error-898-15/TikTokTV/releases).
2. Copy it to your TV with a USB drive, or use a file-transfer app like Send Files to TV.
3. On the TV, enable **Install unknown apps** in Settings for your file manager.
4. Open the APK with a file manager and install it.
5. Launch **TikTok TV** and enjoy.

## Build from source

The project is built with Gradle and GitHub Actions.

```bash
git clone https://github.com/error-898-15/TikTokTV.git
cd TikTokTV
./gradlew assembleDebug
```

The APK will be at `app/build/outputs/apk/debug/`.

You can also build it online: push to GitHub and open the **Actions** tab to download the build.
